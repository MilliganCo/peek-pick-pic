# Peek Pick Pic

## Описание

Desktop-утилита на `PyQt5` для закрепления и управления изображениями поверх экрана. Судя по коду, проект ориентирован на быстрый просмотр, позиционирование, профили настроек и работу с оверлейными окнами в Windows.

## Возможности

- показ изображения поверх других окон;
- управление положением и размерами overlay-окна;
- работа с профилями через реестр Windows;
- системный трей и горячие клавиши;
- сохранение пользовательских настроек.

## Стек

- Python
- PyQt5
- pywin32
- keyboard

## Запуск

```bash
pip install PyQt5 pywin32 keyboard
python ppp10.py
```
